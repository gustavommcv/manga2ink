The volume editor decides which of your chapters belong to each volume. All three **Chapters from** tabs work on the same volumes, so you can edit a suggestion just as you can build volumes from scratch.

## File names

If the names contain volume numbers, **File names** shows a summary of the volumes it recognized. It does not guess where a volume ends from the usual number of chapters.

If the summary needs correcting, use **Edit chapter mapping** to open the manual controls. **Start over from the names** goes back to the volumes found in the names and discards your edits.

## Manual: no online lookup needed

1. Select **Manual**. If no volumes were found in names, this tab opens automatically.
2. Use **Create volume 1** to add the first volume.
3. Select chapters in the chapter list, choose the destination volume, and use **Assign selected**. For consecutive numbered chapters, use **Assign range**.
4. Repeat for the other volumes. Assigning an already placed chapter moves it rather than duplicating it.
5. Resolve the listed issues, then use **Confirm mapping**.

Use the editor's controls to change volume numbers or merge volumes. The undo and redo buttons reverse your changes.

## The same chapter twice

A folder sometimes holds the same chapter from two groups, for example `Ch.0002 [G1]` and `Ch.0002 [G2]`. Mangabound cannot choose between the copies, so it leaves **all** of them out of the book. Placing one of them in a volume does not change that. The editor lists this as an error, **Chapter 2 is in the folder more than once**, until you remove all but one of the copies from the folder and add the folder again.

If a book is made anyway and something was left out of it, the results say so under the book. For example, they can say that chapters with more than one copy, chapters missing inside a volume, chapters with no pages, or links that lead outside the folder were left out. These notices are listed in [Saving and ready books](../exporting/#warnings-about-the-books).

A link in a manga folder is followed only when it leads to a file inside that folder. This keeps a folder from someone else from putting a file of yours into a book. To keep such a page, put a copy of the file in the folder.

## Folders whose names are not chapter names

Mangabound looks for a chapter number in the name of each folder. A folder whose name it cannot read (`Omake`, `Ch.004 [GroupA]`, or a name in another script with no number) ends up in no volume and in no book, and the editor cannot place it, because it does not know which chapter it is. The queue row and the editor list these folders by name under **Folders left out**.

Rename the folders so that they include a chapter number, for example `Ch.005`, and add the folder again. For a library, the queue row shows each title with the folders left out of it, and the editor of that title lists them. After renaming, add the library again.

A series kept in a library as a link to a folder is not read either, because links to a series are not followed. The screen with the library's titles lists the folders that were left out, by name, above the list. If every folder of the library is a link, its queue row says so, rather than asking you to turn grouping off. Put the real folders in the library and add it again.

## Online source: optional suggestions

Choose **Online source**, select MangaDex, enter the title, and press **Search**.

Choose the matching work with **Use these volumes**, review the summary, then confirm it or use **Edit chapter mapping**. An online suggestion may be incomplete or differ from your edition, so check special and decimal chapters. If the work is not listed, use **Manual**.

## Skipping grouping

**Skip grouping** is available where Mangabound can convert without regrouping. It is turned off in **Create one book for the series** mode, because that mode needs the volumes to build the EPUB's contents, with chapters under their volumes.

The editor passes your volumes to mangabind in a [documented metadata format](https://github.com/gustavommcv/mangabind/blob/main/docs/adr/0010-local-metadata-file.md). You never need to edit that file yourself.
