## Device and format

Choose your model under **Device**. To set the page size yourself, open **Advanced conversion options** and fill in **Custom width** and **Custom height** in pixels. A custom device profile requires both dimensions. On the command line these are `--profile`, `--format`, `--customwidth` and `--customheight`; the [mangapress CLI](../../cli/mangapress/) page shows what each does.

| Format | When to choose it                                                                                         |
| ------ | --------------------------------------------------------------------------------------------------------- |
| CBZ    | The starting format. Processed images in a ZIP archive: the one KOReader's own guide recommends for manga |
| EPUB   | A book with chapter navigation and an author; the single-series-book mode requires it                     |
| PDF    | Fixed pages for a reader or tablet that supports PDF                                                      |

Compatibility depends on the reader application as well as the device. Kindle's native reader does not directly open EPUB: use a compatible transfer/conversion service or an installed reader such as KOReader. KOReader treats EPUB differently from CBZ/PDF: it lays an EPUB out as text, with its own margins and status bar around each page, so a page can come out smaller than the screen. See [reader settings](../../koreader/recommended-settings/).

## Advanced conversion options

**Advanced conversion options** exposes mangapress's settings, grouped by purpose: **Reading**, **Double-page spreads**, **Size and borders**, **Cropping**, **Two-page view**, **Color and tone**, **Page images**, **Cover** and **Book metadata**. Start with the device defaults; change one setting at a time and check the resulting book. If artwork is cut off, reduce or disable cropping.

Every group has a page of its own in the [overview](../advanced-options/), where the same page is converted with and without each option, and where every option is listed with the command-line flag that sets it.

Some options only matter after another. Pages kept in color stay JPEG even when **Page format** is PNG, until **Color pages as PNG too** is on, as the controls below show; the [Page images](../advanced-options/page-images/) page measures what each costs.

**Use the images as they are**, beside the device, packages the pages untouched, and **Name the book .epub**, also beside the device, keeps a Kobo's EPUB from being named `.kepub.epub`: see [Page images](../advanced-options/page-images/#use-the-images-as-they-are) and [Book metadata](../advanced-options/book-metadata/#name-the-book-epub).

An option that another choice leaves without effect stays visible, dimmed, and says why. **Webtoon strips**, for example, locks the options a webtoon never uses ([Reading](../advanced-options/reading/#what-else-changes-with-it) lists them), and what you had chosen comes back when you return to pages.

Modified fields can be reset individually, or together with **Reset to defaults**. Settings are kept between launches.

## One book for the series

Enable **Create one book for the series** in the queue to combine its chapters and volumes into one book, with chapters nested under their volumes in the table of contents.

This mode uses EPUB and keeps both process steps enabled. Turn it off to change the format or steps. Larger combined books can take longer to open on an e-reader.
