## Which input should I add?

| What you have                                      | What to add                                                         |
| -------------------------------------------------- | ------------------------------------------------------------------- |
| A manga's chapter folders or separate chapter CBZs | Their containing manga folder                                       |
| Several manga folders in one library directory     | The library folder; inspect its individual titles before processing |
| A complete volume already in a CBZ                 | The CBZ itself                                                      |

Use **Files** or **Folder**, or drag files and folders onto the queue. Clicking the drop area offers the same choices. Mangabound inspects what you add before converting. A chapter folder with missing or conflicting volume assignments may need your review.

## Review an item

Use **Edit volumes** to say which chapters belong to which volume. A library opens a list of its titles, so you can review each manga on its own. Removing an item from the queue does not delete its files.

Use the book-details action to set the **Series title** or **Book title**, the **Author** and the **Language** of each item. You can type the author yourself or look it up online. For a library, set these details for each title.

If the folder names show that the manga is in a different language from the books you are making, the **Language** field offers a button to use it, such as **Use pt-BR**. Nothing changes until you click it. You can type a language in any capitalization: books always use the standard form, so `pt-br` becomes `pt-BR`.

### Options for one item

The sliders button on a row opens the conversion options for that item only. It opens the same page as **Advanced conversion options**, so the device, the format and every other choice are there, and what you change applies to this item alone. A library has the button on each of its titles.

A colored button means the item has options of its own. **Use the queue’s options** on that page removes them again.

On that page, an option is shown in color when it differs from the queue's. The arrow beside it, **Use the queue’s value**, sets that one option back to the queue's value. **Use the queue’s options** does this for all of them. Once an option is set back, the item follows the queue for it again.

When some items have options of their own, the queue's **Advanced conversion options** page shows a notice that says how many. **Use the queue’s options for all** removes all of them at once. **Reset to defaults** on that page only resets the queue's own options. It leaves what the items set.

An item keeps following the queue for everything it has not set. If you change the queue's device later, an item that never chose a device of its own changes with it.

The options of an item are kept while the queue is open. They are not saved for the next time you start the app.

The button is not shown when you only join volumes, because no conversion runs then. With **Create one book for the series**, the format stays EPUB for every item.

### A cover of your own

The same page has **Covers**, with one line for each book the item makes. A book without a cover of its own uses its first page.

- **Choose cover…** picks an image for that book. You can also drop an image on the line. The image can be anywhere and have any name. Mangabound keeps its own copy, so you can move or delete the original afterwards.
- **Add covers from a folder…** gives the folder's images to the books in order of name: the first image to the first book, the second to the second, and so on. You can also drop a folder, or several images, on the list. A cover you chose by hand is never replaced this way. A cover that came from an earlier folder is.
- You can change or remove each cover on its line. Covers are remembered for that folder or file and come back the next time you add it.

  name="generated/book-covers"

Covers can be JPEG, PNG, WebP, GIF or BMP images. When you choose a file, Mangabound checks that it really is an image. A damaged file, or one that only has an image's name, is not used, and the page tells you.

In a folder, an image that cannot be used keeps its place in the order. The images after it still go to the books they line up with, and its book keeps its first page.

If a cover still cannot be used when the book is made, the error names the book and tells you to remove the cover or choose another image on this page.

The cover options in the [conversion options](../output-profiles/) apply to your covers too. A CBZ keeps a cover of your own whatever those options are. A PDF has no cover. The [Cover](../advanced-options/cover/) page shows what each option does.

## Chapters have no volume names

You do not have to rename your whole collection. Open the volume editor. If no volumes were recognized, it opens **Manual** and offers **Online source** as an optional alternative. Follow [volume mapping](../mapping-editor/).

A single chapter CBZ that you add as a file is treated as a complete volume. Add its folder instead if you want it grouped with other chapters.
