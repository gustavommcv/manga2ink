## Choose settings for your book

KOReader treats EPUB differently from CBZ and PDF, so the page controls you get depend on the book format. CBZ is the format Mangabound starts with and the one KOReader's own guide recommends for manga. It has the image-page controls described below. EPUB is useful if you want a table of contents with chapters and volumes, but KOReader draws its pages with margins and a status bar around them.

Start with a few pages and adjust the settings below to suit your screen. Menu names and places can change with the KOReader version, language and device. The [official KOReader guide](https://koreader.rocks/user_guide/) explains the controls of each format and how to search the menus.

The captures below were taken on a **Kindle 2024 running KOReader 2026.07.2-198**. The menus are in English, and the red outlines mark each option.

## Overlap status bar

With a book open, find **Status bar → Overlap status bar**. This lets the page use the area reserved for the status bar. Check that the bar does not cover artwork you want to see.

## Full refresh rate

On an e-ink reader, try **Screen → E-ink settings → Full refresh rate → Every page** if you see traces of the previous page.

A full refresh can reduce these traces, but may add a visible flash or slow page turns. Compare it with the default on your device. This setting applies to supported e-ink screens, not LCD displays. See the [KOReader guide](https://koreader.rocks/user_guide/) for refresh options.

## CBZ/PDF page controls

Try a view that shows one page at a time, with the zoom set to fit the whole page. If the book already fills the screen, leave cropping off: the conversion may already have removed the margins, and cropping again could cut off artwork.

These controls are for CBZ and PDF. For EPUB, use the options in its own reading menu. Change one setting at a time and compare a few pages before you save your preferences.

KOReader also has **Panel Zoom** for manga and comics. It is in the top menu, under the document icon, and works with CBZ and PDF: a long press on a panel zooms in on it. The [official guide](https://koreader.rocks/user_guide/) has the details.

## Tweak document settings

To give a manga folder different defaults from your text books, use KOReader's advanced **Tweak document settings** plugin. It applies defaults for a folder when a book is opened for the first time.

The plugin uses a Lua configuration file, not EPUB style tweaks. Follow the [official setup instructions](https://github.com/koreader/koreader/wiki/Tweak-document-settings-by-directory) and back up your configuration before you edit it. Books you have already opened can keep their own settings.

If the plugin is missing, enable **Tweak document settings** under **Tools → Plugin management**. Then open **Tools → More tools → Tweak document settings**.

3. Inside the existing table, add an entry like this. Replace the path with the manga folder on your reader; preserve the other entries and the file structure.

```lua
["/mnt/us/library/mangas"] = {
    ["inverse_reading_order"] = true,
},
```

This example swaps tap zones and swipe directions for right-to-left reading; it does not configure screen refresh or the status bar. The path is an example Kindle folder, not a folder created by Mangabound.

## Saving a default

Some controls let you save a default with a long press. Others open help or another dialog. Follow the confirmation that KOReader shows for that control. Books you have already opened may keep their own settings.

If a book still displays incorrectly, include the KOReader version, the device, the file format and your settings when you ask for help.
