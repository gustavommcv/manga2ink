## Ajustes para o seu livro

O KOReader trata EPUB de um jeito diferente de CBZ e PDF, então os controles de página que você tem dependem do formato do livro. CBZ é o formato com que o Mangabound começa e o que o guia do próprio KOReader recomenda para mangá. Ele tem os controles de página de imagem descritos abaixo. O EPUB é útil se você quer um índice com capítulos e volumes, mas o KOReader desenha as páginas dele com margens e barra de status em volta.

Abra algumas páginas e experimente os ajustes abaixo na sua tela. Os nomes e o lugar dos menus podem mudar conforme a versão, o idioma e o dispositivo. O [guia oficial do KOReader](https://koreader.rocks/user_guide/) explica os controles de cada formato e como pesquisar nos menus.

Estas capturas foram feitas em um **Kindle 2024 com KOReader 2026.07.2-198**. Os menus estão em inglês, e os destaques vermelhos marcam cada opção.

## Overlap status bar

Com um livro aberto, procure **Status bar → Overlap status bar**. A opção permite que a página use a área reservada à barra de status. Confira se a barra não cobre detalhes que você quer ver.

## Full refresh rate

Em um leitor e-ink, experimente **Screen → E-ink settings → Full refresh rate → Every page** se aparecerem marcas da página anterior.

A atualização completa pode reduzir essas marcas, mas também causar um flash visível ou tornar a troca de páginas mais lenta. Compare com o padrão no seu aparelho. A opção se aplica a telas e-ink compatíveis, não a telas LCD. Consulte as opções de atualização no [guia do KOReader](https://koreader.rocks/user_guide/).

## Controles de página para CBZ/PDF

Experimente uma exibição que mostre uma página por vez, com o zoom ajustado para caber a página inteira. Se o livro já ocupa bem a tela, deixe o recorte desativado: a conversão pode já ter removido as margens, e recortar de novo pode cortar a arte.

Esses controles são para CBZ e PDF. Para EPUB, use as opções do próprio menu de leitura. Altere um ajuste por vez e compare algumas páginas antes de salvar as suas preferências.

O KOReader também tem o **Panel Zoom**, para mangás e quadrinhos. Ele fica no menu superior, sob o ícone de documento, e funciona com CBZ e PDF: um toque longo em um quadro aproxima esse quadro. O [guia oficial](https://koreader.rocks/user_guide/) tem os detalhes.

## Tweak document settings

Para usar padrões diferentes em uma pasta de mangás e em outra de livros de texto, há o plugin avançado **Tweak document settings**. Ele aplica os padrões da pasta quando um livro é aberto pela primeira vez.

O plugin usa um arquivo de configuração Lua, e não os ajustes de estilo de EPUB. Siga as [instruções oficiais](https://github.com/koreader/koreader/wiki/Tweak-document-settings-by-directory) e faça backup antes de editar a configuração. Livros que você já abriu podem manter os próprios ajustes.

Se o plugin não aparecer, ative **Tweak document settings** em **Tools → Plugin management**. Depois abra **Tools → More tools → Tweak document settings**.

<TutorialImage
  name="koreader/tweak-menu"
  alt="Menu More tools com Tweak document settings destacado."
/>

<details>
<summary>Ver passo a passo</summary>

1. Selecione o ícone de ferramentas no menu superior e abra **More tools**.

<TutorialImage name="koreader/tweak-tools" alt="Menu Tools com More tools destacado." />

2. Toque em **Tweak document settings** para abrir **directory_defaults.lua**.

<TutorialImage
  name="koreader/tweak-menu"
  alt="Menu More tools com Tweak document settings destacado."
/>

<TutorialImage
  name="koreader/tweak-editor"
  alt="Editor de directory_defaults.lua mostrando uma configuração de leitura da direita para a esquerda."
/>

3. Dentro da tabela existente, adicione uma entrada como esta. Troque o caminho pela pasta de mangás no seu leitor; mantenha as outras entradas e a estrutura do arquivo.

```lua
["/mnt/us/library/mangas"] = {
    ["inverse_reading_order"] = true,
},
```

Esse exemplo troca as zonas de toque e a direção dos gestos para leitura da direita para a esquerda; não configura a atualização da tela nem a barra de status. O caminho é apenas um exemplo de pasta em Kindle, não uma pasta criada pelo Mangabound.

4. Use **Save** para salvar. Os padrões se aplicam aos livros dessa pasta que ainda não foram abertos; livros já abertos podem manter suas configurações.

</details>

## Salvando um padrão

Alguns controles permitem salvar um padrão com um toque longo. Outros abrem uma ajuda ou outro diálogo. Siga a confirmação que o KOReader mostra para aquele controle. Livros que você já abriu podem manter os próprios ajustes.

Se um livro continuar sendo exibido de forma incorreta, informe a versão do KOReader, o dispositivo, o formato e os seus ajustes ao pedir ajuda.
