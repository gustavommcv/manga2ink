### Windows x64

<ReleaseDownloads platform="windows" />

Use o instalador para uma instalação normal. Na versão portátil, extraia o ZIP e execute o programa dentro da pasta extraída.

O instalador alfa não é assinado com um certificado comercial, então o Windows SmartScreen pode mostrar um aviso. Continue só se você baixou o arquivo da página oficial de versões. Não desative a segurança do Windows por causa disso.

</TabItem>
<TabItem label="macOS">

### macOS Apple Silicon

<ReleaseDownloads platform="macOS" />

Extraia o ZIP e mova **Mangabound.app** para **Applications**. Ainda não há pacote para Mac Intel.

O aplicativo alfa não é notarizado pela Apple, então o macOS pode se recusar a abri-lo. Se isso acontecer, abra **Ajustes do Sistema → Privacidade e Segurança** e escolha **Abrir Mesmo Assim**, se o botão aparecer. [A Apple explica os passos](https://support.apple.com/pt-br/102445). Não desative o Gatekeeper por causa disso.

</TabItem>
<TabItem label="Linux">

### Linux x64

Escolha o pacote da sua distribuição:

<ReleaseDownloads platform="linux" />

Abra um terminal na pasta com o arquivo baixado e execute o comando da sua distribuição. No comando, troque `package.deb`, `package.rpm` ou `package.pkg.tar.zst` pelo nome exato do arquivo que você baixou. Não renomeie o arquivo.

**[Debian / Ubuntu](https://documentation.ubuntu.com/project/contributors/bug-fix/install-built-packages/)**

```bash
sudo apt install ./package.deb
```

**[Fedora](https://dnf.readthedocs.io/en/latest/command_ref.html#install-command)**

```bash
sudo dnf install ./package.rpm
```

**[Arch Linux](https://man.archlinux.org/man/pacman.8.en)**

```bash
sudo pacman -U ./package.pkg.tar.zst
```

Depois, abra **Mangabound** pelo menu de aplicativos. Use `sudo` apenas para instalar, não para abri-lo.

## Confira o download

Cada versão tem um arquivo `SHA256SUMS`. Ele lista o checksum de todos os outros arquivos daquela versão. Para conferir os seus downloads:

1. Coloque `SHA256SUMS` na pasta com os arquivos que você baixou.
2. Execute `sha256sum -c SHA256SUMS`. No macOS, execute `shasum -a 256 -c SHA256SUMS`.

No Windows, execute `Get-FileHash <arquivo>` no PowerShell e compare o valor com a linha daquele arquivo em `SHA256SUMS`.

Um arquivo que não está na pasta é informado como ausente, e um que não confere é informado como falho.

Um checksum que confere mostra que o arquivo é o que a versão publicou e que chegou inteiro. Ele não mostra onde os arquivos foram construídos, e ainda não existe um atestado de build (um registro assinado de onde o arquivo foi gerado). As versões anteriores à alpha.11 não têm `SHA256SUMS`.

## Se a instalação falhar

Confira se você baixou o pacote do seu sistema e da sua arquitetura. Se o Mangabound disser que o mangabind ou o mangapress “could not be verified” (não pôde ser verificado), reinstale o Mangabound pela página oficial de versões. Não troque as ferramentas por arquivos de outra origem.
