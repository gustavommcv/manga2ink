お使いのシステム向けの最新バージョンを下からダウンロードするか、[すべてのリリース](https://github.com/gustavommcv/manga2ink/releases)を確認してください。

<Tabs>
<TabItem label="Windows">

### Windows x64

<ReleaseDownloads platform="windows" />

通常のインストールにはインストーラーを使います。ポータブル版を使う場合は、ZIP を展開し、展開したフォルダー内のプログラムを実行してください。

アルファ版のインストーラーは商用の証明書で署名されていないため、Windows SmartScreen が警告を表示することがあります。公式のリリースページからダウンロードした場合に限り、続行してください。このために Windows のセキュリティを無効にしないでください。

</TabItem>
<TabItem label="macOS">

### macOS Apple Silicon

<ReleaseDownloads platform="macOS" />

ZIP を展開し、**Manga2Ink.app** を**アプリケーション**フォルダーに移動してください。Intel Mac 向けのパッケージはまだありません。

アルファ版のアプリは Apple の公証（notarization）を受けていないため、macOS が開くのを拒否することがあります。その場合は**システム設定 → プライバシーとセキュリティ**を開き、ボタンが表示されていれば**このまま開く**を選んでください。[Apple による手順の説明](https://support.apple.com/ja-jp/102445)があります。このために Gatekeeper を無効にしないでください。

</TabItem>
<TabItem label="Linux">

### Linux x64

お使いのディストリビューション向けのパッケージを選んでください:

<ReleaseDownloads platform="linux" />

ダウンロードしたファイルのあるフォルダーでターミナルを開き、お使いのディストリビューション用のコマンドを実行します。コマンド中の `package.deb`、`package.rpm`、`package.pkg.tar.zst` は、ダウンロードしたファイルの正確な名前に置き換えてください。ファイル名は変更しないでください。

**[Debian / Ubuntu](https://documentation.ubuntu.com/project/contributors/bug-fix/install-built-packages/)**

```bash
sudo apt install ./package.deb
```

**[Fedora](https://dnf.readthedocs.io/en/latest/command_ref.html#install-command)**

```bash
sudo dnf install ./package.rpm
```

**[Arch Linux](https://man.archlinux.org/man/pacman.8.en)**

```bash
sudo pacman -U ./package.pkg.tar.zst
```

その後、アプリケーションメニューから **Manga2Ink** を開きます。`sudo` はインストールのときだけ使い、アプリの実行には使わないでください。

## ダウンロードを確認する

各リリースには `SHA256SUMS` というファイルがあります。そのリリースにある他のすべてのファイルのチェックサムが書かれています。ダウンロードしたファイルを確認するには:

1. `SHA256SUMS` を、ダウンロードしたファイルと同じフォルダーに置きます。
2. `sha256sum -c SHA256SUMS` を実行します。macOS では `shasum -a 256 -c SHA256SUMS` を実行します。

Windows では、PowerShell で `Get-FileHash <ファイル名>` を実行し、その値を `SHA256SUMS` の該当ファイルの行と比べます。

フォルダーにないファイルは見つからないものとして、一致しないファイルは失敗として報告されます。

チェックサムが一致すれば、そのファイルがリリースで公開されたものであり、欠けずに届いたことが分かります。ただし、ファイルがどこでビルドされたかは分かりません。ビルドの証明（ファイルがどこで作られたかを示す署名付きの記録）もまだありません。alpha.11 より前のリリースには `SHA256SUMS` がありません。

## 更新する

**アプリの設定**（タイトルバーの歯車）を開き、**更新**を選んで**更新を確認**をクリックします。新しいバージョンがあると、そのバージョンと公開日が表示され、**更新をダウンロード**を押すとブラウザーでダウンロードページが開きます。アプリはまだ自動ではインストールしません。お使いのシステム用のファイルをダウンロードし、最初のときと同じように、今あるものの上にインストールしてください。クリックしないかぎり、何も確認しません。

## インストールに失敗したら

お使いのシステムとアーキテクチャ向けのパッケージをダウンロードしたか確認してください。Manga2Ink が mangabind または mangapress を「検証できませんでした」と表示した場合は、公式のリリースページから Manga2Ink をインストールし直してください。ツールを、ほかの入手元のファイルに置き換えないでください。

## 問題を報告する

[issue を作成](https://github.com/gustavommcv/manga2ink/issues)し、バージョン、お使いの OS、やろうとしていたこと、起きたことを書いてください。**アプリの設定**の**このアプリについて**にある**トラブルシューティング**の**診断情報をコピー**を使うと、バージョンとお使いのシステムがクリップボードに入ります（パスや名前は含まれません）。報告に貼り付けてください。クラッシュや変換の失敗の場合は、エラーメッセージをそのまま添えてください。**ログフォルダーを開く**で開くログファイルを添付する場合は、先に内容を確認してください。本やフォルダーのパスが含まれていることがあります。詳しくは[アプリの設定](../../user-guide/app-settings/#このアプリについて)を見てください。
