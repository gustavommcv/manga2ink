Manga2Ink は、同梱のツールをサブプロセスとして実行し、その構造化された出力を検証します。`--protocol-version` を使うと、ツールのバージョン、プロトコル、機能を読み取れます。

## 規範となる契約

- [mangabind マシンプロトコル v1](https://github.com/gustavommcv/mangabind/blob/main/docs/machine-protocol-v1.md): `--json` は、最終レポートを 1 つ stdout に返します。任意の `--progress-json` を付けると、最終レポートはそのままに、進み具合を stderr にも報告します。
- [mangaprep マシンプロトコル v1](https://github.com/gustavommcv/mangaprep/blob/main/docs/machine-protocol-v1.md): `--json-events` は、連番の付いた JSON Lines を stdout に出力します。

各契約が、メッセージのフィールド、進捗のストリーム、エラー、終了コードを定めています。

## アプリでの動作例

アプリの[記録されたプロトコルのフィクスチャ](https://github.com/gustavommcv/manga2ink/tree/main/tests/fixtures/protocol)と[アダプターのパーサー](https://github.com/gustavommcv/manga2ink/tree/main/src/adapters)が、実際に受け付けるペイロードを示しています。[ツールチェーンのロック](https://github.com/gustavommcv/manga2ink/blob/main/toolchain.lock.json)は、同梱のバージョンを記録しています。

連携をテストするときは、対象のリリースのフィクスチャを使ってください。
