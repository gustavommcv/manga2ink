ローカルネットワーク経由で、本を KOReader と共有します。リーダーで Mangabound の **OPDS catalog** を開き、ダウンロードする本を選びます。

## 共有を始める

1. 結果画面の **Share these books** を使うと、保存できる状態の本を共有できます。または、タイトルバーの **Share** を使って、既存のライブラリフォルダーを選びます。

   **Share these books** は、準備ができたすべての本を共有します。今回の変換の本と、**Ready books** にまだ残っている以前の変換の本が対象です。共有中に変換した本も、リーダーに表示されます。本を共有している間は、保留中の変換を削除できません。先に共有を停止してください。

2. リーダーから届くネットワークに対応する **Network interface** を選びます。リーダーが Wi-Fi を使っていても、イーサネットで問題ありません。両方の端末が届くネットワークでない限り、VPN アダプターは避けてください。Mangabound は選択を記憶します。
3. 必要なら **Username** と **Password** の両方を入力します。両方とも空のままでもかまいません。
4. **Start sharing** を選び、アプリに表示されたアドレスを **Copy** します。ダウンロードが終わるまで Mangabound を開いたままにしてください。

アドレスは `http://192.168.1.150:48123/` のような形です。実際には、アプリに表示されたものを使ってください。

**Recently converted** を開くと、最新の本が最初に見つかります。**Other files** には、共有ライブラリにあるその他の本が並びます。

:::caution[信頼できるローカルネットワークのみ]
共有には HTTP を使います。任意の Basic 認証でアクセスを制限できますが、認証情報や本は暗号化されません。ポートをインターネットに公開したり、信頼できないネットワークで使ったりしないでください。
:::

[KOReader の接続](../connecting/)に進みます。

終わったら **Stop sharing** を使います。すぐに終了し、その時点でダウンロード中の本は途中で切れます。Mangabound は、1 分間無通信の接続も切断します。たとえば、ダウンロードの途中でスリープに入った電子書籍リーダーです。

## 本が表示されない場合

Mangabound は、共有フォルダーの中にあるファイルだけを共有します。外の場所へのリンク（シンボリックリンクまたはジャンクション）になっているサブフォルダーはたどられないため、その中の本は共有されず、アプリのログに、どの本が除外されたかが記録されます。代わりに、本が実際にあるフォルダーを共有してください。

<span id="if-your-reader-cannot-connect"></span>

## リーダーが接続できない場合

次を確認してください:

- 両方の端末が同じローカルネットワークにある。
- 選んだネットワークインターフェースが正しい。
- 共有がまだオンになっている。
- ファイアウォールが、その信頼できるネットワークでアプリを許可している。

クライアント分離のあるゲスト Wi-Fi や VPN は、両方の端末がインターネットに接続できていても、アクセスを妨げることがあります。コンピューターの IP アドレスが変わった場合は、KOReader のカタログのアドレスを更新してください。

Mangabound は、実行しているコンピューター自身のアドレスにだけ応答します。アプリが表示する数字（`192.168.1.150` など）、`localhost`、またはコンピューター自身の名前です。それ以外の名前で届いた要求は拒否されます。これは、たまたま開いた Web ページが、ブラウザーを通じてカタログに届くのを防ぐためです。ルーターがコンピューターに独自の名前を付け、リーダーがその名前を使っている場合は、代わりにアプリに表示されたアドレスを使ってください。どの名前が拒否されたかは、アプリのログに記録されます。
