タイトルバーの右にある歯車、または Windows と Linux では Ctrl+,、Mac では Cmd+, で**アプリの設定**を開きます。変更は行った時点で保存されるので、保存の操作は要りません。Esc でダイアログを閉じられます。タブは 4 つあります。ここで選ぶのはアプリ自体のことで、本のことではありません。変換のオプションはキューに残ります。

## インターフェース

<TutorialImage
  name="generated/app-settings-interface"
  alt="アプリの設定のインターフェースのタブ。言語とテーマの選択肢と、日本語についての注記があります。"
/>

- **言語**は、システムの言語に従う**自動（システムの言語）**、**English**、**Português (Brasil)**、**日本語**から選びます。すぐに反映されます。本、タイトル、変換ツール自身のメッセージは翻訳されません。アプリの日本語は AI の支援で作られていて、日本語を話す方による確認はまだ十分ではありません。アプリが日本語のあいだは、選択肢の下にその旨の注記と、誤りを報告するページを開くボタンが表示されます。
- **テーマ**は、アプリが最初に使う**自動（システムのテーマ）**（システムのダーク／ライトの設定に合わせ、アプリを開いたままシステムの設定を変えても追従します）、**ダーク（グラファイト）**、**ライト（ペーパー）**のいずれかです。ウィンドウのタイトルバーを含め、すぐに反映されます。このガイドの画像はダークテーマの画面です。

## 処理

<TutorialImage
  name="generated/app-settings-processing"
  alt="アプリの設定の処理のタブ。Manga2Ink が作業するフォルダー、その空き容量、保存待ちの本が表示されています。"
/>

このタブは、アプリが作業する場所と、変換中の動作についてのものです。

- **作業フォルダー**は、変換中に Manga2Ink がボリュームを作り、保存するまで完成した本を置いておくフォルダーです。選ぶまでは **Manga2Ink が選択**と表示されます。**フォルダーを選択…**で空き容量を確認しながら別のフォルダーを選び、**初期設定のフォルダーを使う**で元に戻します。何が変わり、何が変わらないかは[Manga2Ink が作業する場所](../exporting/#manga2ink-が作業する場所)を見てください。
- **保存待ちの本**は、待機している本の数、変換の数、使っている容量を示し、7 日、30 日、90 日のあいだ何も変更されていないものを、確認したうえで整理します。[保留中の本を削除する](../exporting/#保留中の本を削除する)を見てください。

<TutorialImage
  name="generated/app-settings-queue"
  alt="処理のタブの末尾。Manga2Ink が変換中に行うことについての選択肢で、オンの 2 つと、自動になっている並列変換があります。"
/>

- **Manga2Ink の変換中**には 3 つの選択肢があります。変更は次に**処理**を押したときから有効で、動いている変換には影響しません。2 つはオフにするまでオンです。**長い変換が終わったら知らせる**は、30 秒を超えた変換が終わり、Manga2Ink のウィンドウが前面にないときに、システムの通知を表示します。**変換中はパソコンをスリープさせない**は、変換が終わるまでコンピューターがスリープに入らないようにします。画面は消えることがあります。**並列変換**は、1 つのタイトルの本を同時にいくつ変換するかで、選ぶまでは**自動**で、お使いのコンピューターでいくつになるかが表示されます。数は 1 からコンピューターに頼める最大まで選べます。詳しくは[Manga2Ink が変換しているあいだ](../exporting/#manga2ink-が変換しているあいだ)を見てください。

## 更新

<TutorialImage
  name="generated/app-settings-updates"
  alt="アプリの設定の更新のタブ。インストール済みのバージョンと、更新を確認ボタンがあります。"
/>

このタブには、インストールされているバージョンが表示されます。**更新を確認**は、クリックしたときだけ、新しいバージョンが出ているかを GitHub に尋ねます。出ていれば、そのバージョンと公開日を伝え、**更新をダウンロード**でダウンロードページがブラウザーで開きます。アプリはまだ自分でインストールしません。お使いのシステム用のファイルをダウンロードし、[更新する](../../getting-started/installation/#更新する)のとおり、今のものの上にインストールしてください。

**更新を自動的に確認**と**確認するバージョン**は表示されますが、まだ変更できません。アプリが自分で更新できるようになったときに使えるようになります。それまでは、これまでのリリースがすべてプレリリースなので、確認では安定版とプレリリースの両方を探します。

## このアプリについて

<TutorialImage
  name="generated/app-settings-about"
  alt="アプリの設定のこのアプリについてのタブ。バージョン、ガイド、リポジトリ、リリースノート、問題報告へのリンク、変換ツール、診断情報をコピーするボタンとデータとログのフォルダーを開くボタンが表示されています。"
/>

**このアプリについて**には、アプリが何であるかと、動いているバージョンが表示されます。**ユーザーガイド**、**GitHub**、お使いのバージョンの**リリースノート**、**問題を報告**へのリンクがあり、**変換ツール**（mangabind と mangapress）を、バージョンと、起動のたびにアプリが行う確認に通ったかどうかとともに一覧にします。

同じタブの**トラブルシューティング**は、問題を報告するときに役立ちます。

- **診断情報をコピー**は、アプリとその実行環境のバージョン、システムとマシン（システムのバージョン、プロセッサー、メモリ）、ウィンドウの言語、作業フォルダーを選んだかどうか（どれかは含みません）、変換ツールが確認に通ったかどうかをクリップボードに入れます。パス、本やフォルダーの名前、ログの内容は含まれません。報告に貼り付けてください。[問題を報告する](../../getting-started/installation/#問題を報告する)を見てください。
- **データフォルダーを開く**と**ログフォルダーを開く**は、それぞれのフォルダーをファイルマネージャーで開きます。ログファイルにはうまくいかなかったことが記録され、本やフォルダーのパスが含まれていることがあります。共有する前に内容を確認してください。

これらによって何かがどこかへ送られることはありません。**プロジェクトを支援する**は、プロジェクトを支援できるページを開きます。タブの最後には、クレジットとライセンスがあります。

## アプリが覚えているもの

- **アプリの設定**で選んだこと。専用のファイルに保存され、変換オプションのリセットでは変わりません。
- ウィンドウの大きさと位置。Manga2Ink は、最後に使ったとおりに開きます。大きさ、最大化していたかどうか、そしてシステムがプログラムによるウィンドウの配置を認めている場合は位置です。Linux の Wayland ではプログラムがウィンドウの位置を決められないため、そこでは大きさと最大化しているかどうかだけが保存され、タイリング型のウィンドウマネージャーでは、並べられたウィンドウの大きさをマネージャー自身が決めます。
- 変換オプション。これまでと同じです。再起動したときに本がどう残るかは[再起動後に残るもの](../exporting/#再起動後に残るもの)を見てください。
