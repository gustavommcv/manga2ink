## 端末と形式

**端末**でお使いのモデルを選びます。ページサイズを自分で決めるには、**詳細な変換オプション**を開き、**幅の指定**と**高さの指定**をピクセルで入力します。**Other** の端末では、両方が必須です。コマンドラインでは、これらの設定は `--profile`、`--format`、`--customwidth`、`--customheight` です。それぞれの働きは、[mangaprep CLI](../../cli/mangapress/) のページで確認できます。

| 形式 | 選ぶ場面                                                                                                                               |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------- |
| CBZ  | Manga2Ink が最初に選ぶ形式です。処理した画像を ZIP アーカイブにまとめたもの。KOReader 自身のガイドも、マンガにはこの形式を勧めています |
| EPUB | 各話のナビゲーションと著者の情報を持つ本                                                                                               |
| PDF  | PDF に対応するリーダーやタブレット向けの、固定ページ                                                                                   |

何が使えるかは、端末だけでなく、読むアプリにも左右されます。Kindle 自身のリーダーは、EPUB を直接は開きません。Amazon の Send to Kindle のように変換してくれるサービスでファイルを送るか、KOReader のように、自分でインストールしたアプリで読んでください。KOReader は、EPUB を CBZ や PDF とは違うやり方で扱います。EPUB をテキストのようにレイアウトし、各ページの周りに独自の余白とステータスバーを付けるため、ページが画面より小さくなることがあります。[リーダーの設定](../../koreader/recommended-settings/)を参照してください。

Kobo 向けの EPUB では、ファイル名の `!` や `%` などの特殊文字を `_` に置き換えます。本の中のタイトルは入力したままです。Kobo に本をコピーするときは、保存先のフォルダー名にも特殊文字を使わないでください。

## 詳細な変換オプション

**詳細な変換オプション**には、mangaprep の設定が、目的ごとにまとめられています。**読み方**、**見開きページ**、**サイズと縁**、**トリミング**、**2 ページ表示**、**カラーと階調**、**ページの画像**、**表紙**、**本のメタデータ**です。まず端末の既定値から始め、設定を 1 つずつ変更して、できあがった本を確認してください。絵が切れる場合は、トリミングを弱めるか、オフにしてください。

どのグループにも、[概要](../advanced-options/)に専用のページがあります。そこでは、同じページを各オプションあり・なしで変換して見せ、すべてのオプションを、それを設定するコマンドラインのフラグとともに一覧にしています。

あるオプションは、別のオプションがあって初めて意味を持ちます。たとえば、**ページの形式**が PNG でも、**カラーのページも PNG にする**をオンにするまでは、カラーのまま残るページは JPEG のままです。下の操作画面がこれを示し、[ページの画像](../advanced-options/page-images/)のページが、各選択のコストを測定しています。

<TutorialImage
  name="generated/page-images"
  alt="カラー端末向けのカラーと階調とページの画像の操作。グレースケールのページは PNG、カラーのまま残すページは JPEG の品質を選べます。"
  caption="この例では、カラーのページは JPEG のままです。カラーのページも PNG にするをオンにすると、代わりに PNG で保存されます。"

端末のそばに、2 つのオプションがあります。**画像をそのまま使う**は、ページをそのままパッケージ化します（[ページの画像](../advanced-options/page-images/#画像をそのまま使う)）。**本の名前を .epub にする**は、Kobo の EPUB に `.kepub.epub` という名前が付くのを防ぎます（[本のメタデータ](../advanced-options/book-metadata/#本の名前を-epub-にする)）。

別の選択のために意味のなくなったオプションは、薄く表示されたまま残り、その理由が表示されます。たとえば、**ウェブトゥーンの縦長ストリップ**は、ウェブトゥーンでは使われないオプションをロックします（一覧は[読み方](../advanced-options/reading/#what-else-changes-with-it)にあります）。ページに戻すと、選んでいた内容も戻ります。

変更した項目を個別にリセットすることも、**初期設定に戻す**ですべてをリセットすることもできます。設定は、起動をまたいで保持されます。

## シリーズを 1 冊にまとめる

キューで**シリーズを 1 冊の本にする**をオンにすると、その各話と各巻を 1 冊の本にまとめます。このモードはどの形式でも使え、2 つの処理ステップをオンのままにします。ステップを変えるには、オフにしてください。形式は自分で選べて、本に入るものは形式で決まります。

- **EPUB** には目次があり、各話が各巻の下に並びます。
- **CBZ** は、巻と各話をフォルダーとして保ちます。ページを名前順に並べるリーダー（KOReader もそうです）では、順番どおりに表示されます。目次はありません。
- **PDF** はページが順に並び、しおりがあります。各話は各巻の下に並び、リーダーがページの横に一覧で表示します。

長いシリーズで各話の間を行き来したいときは、EPUB か PDF を選んでください。大きくまとめた本は、電子書籍リーダーで開くのに時間がかかることがあります。

  name="generated/single-book"

コマンドラインのツールには独自の既定値があり、アプリのものとは異なります。ターミナルで使う場合は、[mangaprep](../../cli/mangapress/) を参照してください。
