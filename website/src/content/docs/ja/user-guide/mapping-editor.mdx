巻のエディターは、各話がどの巻に入るかを決めます。**Chapters from** の 3 つのタブはすべて同じ巻を扱うので、提案を編集することも、ゼロから巻を作ることもできます。

## File names

名前に巻番号が含まれていれば、**File names** は、認識できた巻の概要を表示します。各話の数が通常どれくらいかから、巻の区切りを推測することはしません。

概要を直す必要がある場合は、**Edit chapter mapping** で手動の操作を開きます。**Start over from the names** を使うと、名前から見つかった巻に戻り、あなたの編集は破棄されます。

## Manual: オンライン検索は不要

1. **Manual** を選びます。名前から巻が 1 つも見つからなかった場合は、このタブが自動的に開きます。
2. **Create volume 1** で最初の巻を追加します。
3. 各話の一覧で話を選び、割り当て先の巻を選んで、**Assign selected** を押します。番号が連続した話には、**Assign range** を使います。
4. ほかの巻についても繰り返します。すでに配置済みの話を割り当てると、重複せずに移動します。
5. 一覧に出た問題を解消してから、**Confirm mapping** を押します。

エディターの操作で、巻の番号を変えたり、巻を統合したりできます。元に戻す・やり直すボタンで、変更を取り消せます。

## 同じ話が 2 つある

1 つのフォルダーに、2 つのグループによる同じ話が入っていることがあります。たとえば `Ch.0002 [G1]` と `Ch.0002 [G2]` です。Mangabound はどちらのコピーを使うかを選べないため、すべてのコピーを本から除外します。そのうちの 1 つを巻に配置しても、結果は変わりません。エディターはこれを **Chapter 2 is in the folder more than once** というエラーとして一覧に出し、コピーを 1 つ残して削除し、フォルダーをもう一度追加するまで、そのままです。

それでも本が作られ、何かが除外された場合は、結果が本の下にそのことを表示します。たとえば、複数のコピーがある話、巻の中で抜けている話、ページのない話、フォルダーの外へ向かうリンクが除外された、といった内容です。これらの通知は、[保存と準備ができた本](../exporting/#warnings-about-the-books)にまとめられています。

マンガのフォルダー内のリンクは、そのフォルダーの中にあるファイルを指している場合にだけたどられます。これは、他人のフォルダーが、あなたのファイルを本に入れてしまうのを防ぎます。そのようなページを残したい場合は、ファイルのコピーをフォルダーに置いてください。

## 名前が話の名前ではないフォルダー

Mangabound は、各フォルダーの名前から、話の番号を探します。名前が読めないフォルダー（`Omake`、`Ch.004 [GroupA]`、または番号のない別の文字体系の名前）は、どの巻にも、どの本にも入らず、どの話か分からないため、エディターで配置することもできません。キューの行とエディターは、これらのフォルダーを、**Folders left out** の下に名前で一覧表示します。

フォルダーの名前を、話の番号を含むもの（たとえば `Ch.005`）に変更して、フォルダーをもう一度追加してください。ライブラリでは、キューの行が各タイトルと、除外されたフォルダーを表示し、そのタイトルのエディターが一覧に出します。名前を変えたら、ライブラリをもう一度追加してください。

ライブラリの中で、フォルダーへのリンクとして置かれたシリーズも読まれません。シリーズへのリンクはたどられないためです。ライブラリのタイトルの一覧の画面は、除外されたフォルダーを、一覧の上に名前で表示します。ライブラリのすべてのフォルダーがリンクである場合、そのキューの行は、グループ分けをオフにするよう求めるのではなく、その旨を表示します。実際のフォルダーをライブラリに置いて、もう一度追加してください。

## Online source: 任意の提案

**Online source** を選び、MangaDex を選択し、タイトルを入力して **Search** を押します。

一致する作品を **Use these volumes** で選び、概要を確認してから、確定するか、**Edit chapter mapping** を使います。オンラインの提案は、不完全だったり、お持ちの版と違ったりすることがあるので、特別編や小数の話の番号を確認してください。作品が一覧にない場合は、**Manual** を使ってください。

## グループ分けを飛ばす

**Skip grouping** は、Mangabound が再グループ化せずに変換できる場面で使えます。**Create one book for the series** モードではオフになります。このモードは、各話をそれぞれの巻の下に置くために、巻が必要だからです。EPUB では目次に、CBZ ではフォルダーとして並びます。

## 巻が保存される場所

エディターは、あなたの巻を、[文書化されたメタデータ形式](https://github.com/gustavommcv/mangabind/blob/main/docs/adr/0010-local-metadata-file.md)で mangabind に渡します。そのファイルを自分で編集する必要はありません。

mangabind が提案した巻を変更すると、Mangabound はその巻をマンガのフォルダーの `mangabind.json` にも保存します。次にそのフォルダーを追加したときに、同じ巻が使えるようにするためです。フォルダーに書き込めない場合や、その `mangabind.json` が正しい JSON でない場合でも、本はあなたの巻で作られます。その下に **The volumes you edited were not kept with the folder** という警告が出て、次回は巻をもう一度編集する必要があることを伝えます。正しい JSON でない `mangabind.json` は、そのまま残されます。

ライブラリのタイトルは別です。mangabind はそのファイルから巻を受け取ります。保存できない場合は、**Confirm mapping** がそのことを伝え、フォルダーに書き込めるようになるまで、そのタイトルは巻が必要なままです。
