[変換設定](../output-profiles/)の **Advanced conversion options** は、本を作る変換ツール mangapress の設定です。そのほとんどは、ページのピクセルを変えます。これらのページは、その方法を示します。実際のページを 1 枚、2 通りに変換し、違うのはそのオプションだけです。

## オプションのグループごとのページ

| ページ                                                | 示すもの                                                                                                                       |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| [読み方（Reading）](reading/)                         | ウェブトゥーンの形をした 1 話を、ページとして変換した場合とストリップとして変換した場合、そして各本の形式が記録する読む方向    |
| [クロップ（Cropping）](cropping/)                     | ページのどれだけが、ピクセル単位で切り落とされるか、そして、切ったあとに何が残るか                                             |
| [色と階調（Color and tone）](color-and-tone/)         | 同じページを、グレースケールとカラー、明るく、暗くしたもの、そして変化の裏づけとなる数値                                       |
| [見開き（Double-page spreads）](double-page-spreads/) | 見開きを、分割する、全体を残す、両方にする場合と、その順序、そして 2 ページ表示が EPUB に書き込むもの                          |
| [サイズと枠（Size and borders）](size-and-borders/)   | ページを画面に合わせる、拡大する、引き伸ばす、画面を埋めるようクロップする方法と、画面と形が違うときにそのまわりにあるもの     |
| [ページ画像（Page images）](page-images/)             | 各ページが保存されるファイル: JPEG か PNG か、グレーの階調の数、そして、それぞれがバイト数でどれだけかかるか                   |
| [表紙（Cover）](cover/)                               | 本の表紙が最初の画像からどう作られるか、どの形式に表紙があるか、そして、幅の広い画像から切り出した表表紙                       |
| [書籍メタデータ（Book metadata）](book-metadata/)     | 各形式がタイトル、著者、言語をどこに保存するか、ComicInfo.xml が何を変えるか、そして、Kobo 向けの本がいつ .kepub.epub になるか |

## すべてのオプション

アプリでの名前、コマンドラインでそれを設定するフラグ、そして、それが説明されている場所を、オプションごとに示します。アプリで見つからないオプション、たとえば `--dry-run` は、コマンドラインだけのものです。

### 端末と出力

- [Device、Book format、Custom width、Custom height](../output-profiles/#device-and-format): `--profile`（`-p`）、`--format`（`-f`）、`--customwidth`、`--customheight`。フラグの働きは、ツール自身の出力とともに、[mangapress の CLI](../../cli/mangapress/#choosing-the-device-and-the-format) にあります。

### 読み方

- [Content](reading/#content): `--webtoon`、または `-w`。
- [Manga reading order](reading/#manga-reading-order): `--manga-style`、または `-m`。分割された見開きに何をするかは、[見開き](double-page-spreads/#manga-reading-order)にあります。

### 見開き

- [Wide pages](double-page-spreads/#wide-pages): `--splitter`、または `-r`。
- [Whole spread first](double-page-spreads/#the-whole-spread-first-upright-or-clockwise): `--rotatefirst`。
- [Keep the whole spread upright](double-page-spreads/#the-whole-spread-first-upright-or-clockwise): `--norotate`。
- [Rotate clockwise](double-page-spreads/#the-whole-spread-first-upright-or-clockwise): `--rotateright`。
- [Restack 4-panel strips as 2×2](double-page-spreads/#restack-4-panel-strips-as-22): `--maximizestrips`。
- [Start on the other side](double-page-spreads/#two-page-view): `--spreadshift`。
- [Invert page turns](double-page-spreads/#two-page-view): `--invertdirection`。
- [One page in landscape](double-page-spreads/#two-page-view): `--onepagelandscape`。

### サイズと枠

- [Page size](size-and-borders/#page-size): **Fit, enlarging small pages** には `--upscale`（`-u`）、**Stretch to the screen** には `--stretch`（`-s`）、**Crop to fill the screen** には `--wallpaper`。
- [Borders](size-and-borders/#borders): `--whiteborders` と `--blackborders`。

### クロップ

- [Page cropping](cropping/#page-cropping): `--cropping`、または `-c`。
- [Cropping power](cropping/#cropping-power): `--croppingpower`。
- [Minimum retained area](cropping/#minimum-retained-area): `--croppingminimum`。
- [Preserved margin](cropping/#preserved-margin): `--preservemargin`。
- [Inter-panel cropping](cropping/#inter-panel-cropping): `--ipc`。

### 色と階調

- [Color pages](color-and-tone/#color-pages): `--forcecolor`。
- [Autocontrast](color-and-tone/#autocontrast): `--colorautocontrast` と `--noautocontrast`。
- [Auto-level black point](color-and-tone/#autocontrast): `--autolevel`。
- [Gamma](color-and-tone/#gamma): `--gamma`、または `-g`。
- [Reduce rainbow effect](color-and-tone/#reduce-rainbow-effect): `--eraserainbow`。

### ページ画像

- [Page format](page-images/#page-format): `--forcepng`。
- [Keep all 256 grays](page-images/#keep-all-256-grays): `--noquantize`。
- [8-bit PNG](page-images/#8-bit-png): `--pnglegacy`。
- [Color pages as PNG too](page-images/#color-pages-as-png-too): `--force-png-rgb`。
- [JPEG quality](page-images/#jpeg-quality): `--jpeg-quality`。
- [Use the images as they are](page-images/#use-the-images-as-they-are): `--noprocessing`。

### 表紙

- [Cut the front cover from a wide image](cover/#cut-the-front-cover-from-a-wide-image): `--smartcovercrop`。
- [Crop the cover to fill the screen](cover/#crop-the-cover-to-fill-the-screen): `--coverfill`。

### 書籍メタデータ

- [書名と著者](book-metadata/#book-title-and-author): `--title`（`-t`）と `--author`（`-a`）。
- [ComicInfo title](book-metadata/#comicinfo-title): `--metadatatitle`。
- [Keep ComicInfo.xml](book-metadata/#keep-comicinfoxml): `--keepcomicinfo`。
- [EPUB language](book-metadata/#epub-language): `--language`。
- [Name the book .epub](book-metadata/#name-the-book-epub): `--nokepub`。

### ツールの動作

- [Quiet mode](../../cli/mangapress/#quieter-output): `--quiet`、または `-q`。
- [変換のプレビュー](../../cli/mangapress/#previewing-a-conversion)は、コマンドラインだけのものです: `--dry-run`、または `-n`。

## 例の作り方

- **例のページ**は、作者がコピーを許可している漫画から取っています。カラーの David Revoy の _Pepper&Carrot_、白黒の Kasuga の _Go Go! Encyclopedia Girls_、そして、背景が黒の Polylerus のページです。クレジットとライセンスは、このページの終わりと、すべての画像の下にあります。
- **変換**は、Mangabound が同梱する mangapress で、Mangabound の初期設定から始めて行います。Kindle Paperwhite 6（1272 × 1696 ピクセル）、CBZ、マンガの読む順序、見開きは両方の形で残す、小さいページは拡大、余白とページ番号はクロップ、です。2 枚の画像の間で違うのは、キャプションにあるオプションだけです。
- **キャプション**には、アプリでの設定の名前、ターミナルから実行したときにその設定が mangapress に渡すフラグ（`フラグなし` が既定です）、そして、mangapress が書き出した各ページのサイズが書かれています（`変換なし` は入力の画像です）。画像をクリックすると、大きく開きます。
- **値の表**は画像ではありません。表にあるタイトル、著者、言語、読む方向、ファイル名は、mangapress が書き出した本から読み戻したもので、行に別の指定がない限り、同じ初期設定で変換したものです。
- **示していないもの。** 自由に使える白黒のマンガには、印刷されたスクリーントーンがほとんどないので、それに依存するもの、たとえばモアレは、画像ではなく説明で扱っています。画像が示すのは、あなたの画面上のピクセルで、リーダーの電子ペーパーの画面ではありません。
