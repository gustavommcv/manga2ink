本のタイトル、著者、言語はファイルに書き込まれ、形式ごとに、それを置く場所が異なるか、そもそも場所がありません。[詳細な変換オプション](../../output-profiles/#詳細な変換オプション)の**本のメタデータ**には、**ComicInfo のタイトル**、**EPUB の言語**、**ComicInfo.xml を保持**があります。本そのもののタイトル、著者、言語は、[マンガを追加する](../../adding-manga/#review-an-item)で説明したとおり、キューの**タイトル、著者、言語を編集**で項目ごとに設定し、**本の名前を .epub にする**は端末のそばにあります。このページは、それらをすべて、実際の本から読み戻します。

例では、_Pepper&Carrot_ の第 6 話の 3 ページを、`Pepper and Carrot 06` という名前のフォルダーに入れて、行に別の指定がない限り、Kindle Paperwhite 6 向けの EPUB に変換します。_Pepper&Carrot_ には ComicInfo.xml がないので、例のために、そのマンガ自身のタイトル、シリーズ番号、著者を書いたものをフォルダーに置いています:

```xml wrap
<ComicInfo>
  <Title>The Potion Contest</Title>
  <Series>Pepper&amp;Carrot</Series>
  <Number>6</Number>
  <Volume>1</Volume>
  <Writer>David Revoy</Writer>
  <LanguageISO>en</LanguageISO>
</ComicInfo>
```

## 形式ごとの保存場所

3 行は、同じタイトル、著者、言語（`--title`、`--author`、`--language`）で変換したものです。

<OptionBook id="metadata-formats" labels={{ epub: 'EPUB', pdf: 'PDF', cbz: 'CBZ' }} />

- **EPUB** は、3 つともパッケージファイルに保存します。
- **PDF** は、タイトルと著者をドキュメントのプロパティに保存し、mangapress は言語を書き込みません。
- mangapress が作る **CBZ** には、ページだけが入り、頼んだ場合は ComicInfo.xml も入ります（後述）。タイトル、著者、言語は入らないので、本はファイル名で識別されます。

## 書名と著者

指定がない場合、タイトルは、入力に ComicInfo.xml があればそこから作られ、なければ入力の名前になります。著者は ComicInfo.xml の `Writer`、または `Unknown` です。`--title` と `--author` はそれらを置き換え、短縮形は `-t` と `-a` です。

<OptionBook
  id="metadata-title-author"
  labels={{
    plain: '何も指定せず、ComicInfo.xml もない',
    info: '何も指定せず、ComicInfo.xml がある',
    title: 'タイトルを指定',
    author: '著者を指定',
    both: '両方を指定',
  }}
/>

アプリでは、本のタイトルと著者は、その詳細にある**シリーズのタイトル**または**本のタイトル**と**著者**から来ます。`--title` と `--author` が届くのは EPUB と PDF だけで、CBZ では何も変わりません。

## ComicInfo のタイトル

ComicInfo.xml がどのタイトルを与えるかは、**ComicInfo のタイトル**の選択で決まります。既定では、シリーズ、巻、番号から作ります。**ComicInfo のタイトルを付け加える**は、そのあとに ComicInfo 自身の `Title` を付け足します。**ComicInfo のタイトルだけを使う**は、その `Title` だけを使い、その場合は、自分で指定したタイトルさえ使われません。`--metadatatitle` は `series-only`、`combine`、`title-only` を受け付けます。

<OptionBook
  id="metadata-comicinfo-title"
  labels={{
    'series-only': 'ComicInfo のタイトル: シリーズ、巻、番号を使う',
    combine: 'ComicInfo のタイトル: ComicInfo のタイトルを付け加える',
    'title-only': 'ComicInfo のタイトル: ComicInfo のタイトルだけを使う',
    'given-series-only': 'タイトルを指定、シリーズ、巻、番号を使う',
    'given-combine': 'タイトルを指定、ComicInfo のタイトルを付け加える',
    'given-title-only': 'タイトルを指定、ComicInfo のタイトルだけを使う',
    'no-info': 'ComicInfo のタイトルだけを使う、ComicInfo.xml なし',
  }}
/>

入力に ComicInfo.xml がなければ、適用するタイトルがなく、最後の行は入力の名前です。指定したタイトルは、1 つの行を除いてすべてで優先されます。**ComicInfo のタイトルだけを使う**がその例外で、それがこの選択の目的だからです。

## ComicInfo.xml を保持

mangapress が作る CBZ には、これをオンにしない限り、ComicInfo.xml は入りません。`--keepcomicinfo` を付けると、入力のものが、書き換えられずにそのままコピーされます。タイトルと著者を指定していても同じです。入力に ComicInfo.xml がなければ、何も入りません。このオプションが効くのは CBZ だけで、アプリは EPUB と PDF では薄く表示します。最後の 2 行は、それらに何も加わらないことを示すために、あえてフラグを付けています。

    epub: 'EPUB, ComicInfo.xml を保持: オン',

  }}

## EPUB の言語

言語は EPUB のパッケージファイルに書き込まれ、指定がなければ `en-US` が使われます。CBZ と PDF には、最初の表が示したとおり、言語は付きません。`--language` は言語コードを受け付けます。

<OptionBook
  id="metadata-language"
  labels={{
    default: 'EPUB の言語: 指定なし',
    ja: 'EPUB の言語: ja',
    'pt-BR': 'EPUB の言語: pt-BR',
    pdf: 'PDF、ja を指定',
    cbz: 'CBZ、ja を指定',
  }}
/>

この設定には、空でないコードが必要です。また、本自身の詳細は、`pt-BR` の形で言語を指定します。詳細で言語を指定した本は、設定ではなく、その言語を使います。[マンガを追加する](../../adding-manga/#review-an-item)を参照してください。

## 本の名前を .epub にする

Kobo 自身のリーダーは `.kepub.epub` という名前を探すため、mangapress は、入力から名前を作るとき、Kobo のプロファイル向けに作る EPUB を、その名前にします。**本の名前を .epub にする**（`--nokepub`）は、普通の `.epub` のままにします。変わるのは名前だけで、中身の本は同じファイルです。カスタムの画面サイズにすると、mangapress はその端末を Kobo として扱わなくなります。ほかの端末向けの本は、もともと `.epub` という名前で、CBZ は常に `.cbz` です。
