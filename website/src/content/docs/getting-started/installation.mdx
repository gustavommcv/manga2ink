### Windows x64

<ReleaseDownloads platform="windows" />

Use the installer for a normal installation. For the portable version, extract the ZIP and run the program inside the extracted folder.

The alpha installer is not signed with a commercial certificate, so Windows SmartScreen may warn you. Continue only if you downloaded it from the official release page. Do not turn off Windows security for this.

</TabItem>
<TabItem label="macOS">

### macOS Apple Silicon

<ReleaseDownloads platform="macOS" />

Extract the ZIP and move **Manga2Ink.app** to **Applications**. There is no package for Intel Macs yet.

The alpha app is not notarized by Apple, so macOS may refuse to open it. If that happens, open **System Settings → Privacy & Security** and choose **Open Anyway**, if the button is there. [Apple explains the steps](https://support.apple.com/en-us/102445). Do not turn off Gatekeeper for this.

</TabItem>
<TabItem label="Linux">

### Linux x64

Choose the package for your distribution:

<ReleaseDownloads platform="linux" />

Open a terminal in the folder with your download and run the command for your distribution. In the command, replace `package.deb`, `package.rpm` or `package.pkg.tar.zst` with the exact name of the file you downloaded. Do not rename the file.

**[Debian / Ubuntu](https://documentation.ubuntu.com/project/contributors/bug-fix/install-built-packages/)**

```bash
sudo apt install ./package.deb
```

**[Fedora](https://dnf.readthedocs.io/en/latest/command_ref.html#install-command)**

```bash
sudo dnf install ./package.rpm
```

**[Arch Linux](https://man.archlinux.org/man/pacman.8.en)**

```bash
sudo pacman -U ./package.pkg.tar.zst
```

Then open **Manga2Ink** from your application menu. Use `sudo` only to install it, not to run it.

## Check your download

Each release has a `SHA256SUMS` file. It lists a checksum for every other file in that release. To check your downloads:

1. Put `SHA256SUMS` in the folder with the files you downloaded.
2. Run `sha256sum -c SHA256SUMS`. On macOS, run `shasum -a 256 -c SHA256SUMS`.

On Windows, run `Get-FileHash <file>` in PowerShell and compare the value with the line for that file in `SHA256SUMS`.

A file that is not in the folder is reported as missing, and a file that does not match is reported as failed.

A matching checksum shows that the file is the one the release published and that it arrived whole. It does not show where the files were built, and there is no build attestation yet (a signed record of where a file was made). Releases before alpha.11 have no `SHA256SUMS`.

## Updating

Open **App settings** (the gear in the title bar), choose **Updates** and click **Check for updates**. If a newer version is out, Manga2Ink says which one and the day it was published, and **Download the update** opens the download page in your browser. The app does not install it for you yet: download the file for your system and install it as you did the first time, over the one you have. Nothing is checked unless you click.

## If installation fails

Check that you downloaded the package for your system and architecture. If Manga2Ink says that mangabind or mangaprep “could not be verified”, reinstall Manga2Ink from the official release page. Do not replace the tools with files from another source.

## Reporting a problem

[Open an issue](https://github.com/gustavommcv/manga2ink/issues) and include the version, your operating system, what you were trying to do and what happened. In **App settings**, **About**, **Troubleshooting**, **Copy diagnostics** puts the versions and your system on the clipboard, with no paths and no names: paste it into the report. For a crash or a failed conversion, include the exact error message. If you attach a log file from **Open the logs folder**, look at it first: it may hold the paths of books and folders. See [App settings](../../user-guide/app-settings/#about).
