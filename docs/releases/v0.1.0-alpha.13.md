# Mangabound v0.1.0-alpha.13

An alpha: the installers are not code-signed. How to install, and what to expect from the system, is in the [installation guide](https://gustavommcv.github.io/mangabound/getting-started/installation/). `SHA256SUMS` checks the downloads.

## Added

- A new app icon, contributed by [JPmarquesbraga](https://github.com/JPmarquesbraga), appears in the desktop packages and user guide.
- The installation guide has direct download buttons for the latest published packages.

## Changed

- New settings start with CBZ, and the format choices list it before EPUB. Existing saved choices stay unchanged; creating one book for the series still requires EPUB.
- The bundled mangapress is updated to 0.8.0. Format selection in the app remains explicit, and custom titles still name the output files.
- Supported PNG or GIF pages that end early can now be recovered. The book keeps the readable part, and the results warn when pages have a blank part. Files whose required headers cannot be read still fail conversion.

## Fixed

- EPUB pages no longer reserve extra line height below their images in KOReader. Convert existing EPUBs again to apply the fix. Reader margins and status-bar settings remain independent.

Bundled: mangabind v0.7.1, mangapress v0.8.0. [Full changelog](https://github.com/gustavommcv/mangabound/compare/v0.1.0-alpha.12...v0.1.0-alpha.13)
