# Manga2Ink v0.1.0-alpha.19

An alpha: the installers are not code-signed. How to install, and what to expect from the system, is in the [installation guide](https://gustavommcv.github.io/manga2ink/getting-started/installation/). `SHA256SUMS` checks the downloads.

## Added

- **Seven fixed-resolution device profiles**, alongside the existing e-reader profiles.

## Changed

- **The conversion tool is now mangaprep 0.9.0**, the new name of mangapress, following Kindle Comic Converter 12.1.1. The app, diagnostics and guide use the new name. It is still bundled with Manga2Ink.
- **Updated device names:** Kindle 11/2026, Kindle Paperwhite 6/2026 and Kobo Clara BW.
- **Boxes, fields and selects have thin edges again in both themes.** They remain below WCAG's control-edge contrast requirement by choice; a higher-contrast theme is not available yet.

## Fixed

- **Updated the schema validator to Zod 4.6.7**, including the fix for excessive memory use when validating oversized collections.
- **The first launch after upgrading from Mangabound imports its settings and window state even if the installer has already created caches in Manga2Ink's data folder.** Installer maintenance runs no longer start the app or interfere with that first launch. Existing Manga2Ink settings are kept.
- **A series kept as one folder or file for each volume can be converted.** Collections such as `第01巻` and `第02巻`, or `v01` and `v02`, no longer stop with a duplicate-chapter error. Chapters numbered again inside each volume's folder also work; actual duplicate chapters in one volume still need to be resolved.
- **Kobo EPUB filenames replace characters that can prevent the reader from opening them.** `Dr. Stone! Vol.01 100%` becomes `Dr. Stone_ Vol.01 100_.kepub.epub`, while the title inside the book stays as typed. This also applies when **Name the book .epub** is selected. Avoid special characters in the destination folder names on the Kobo too.
- **Grayscale gamma and 16-bit page decoding follow KCC 12.1.1.** Pages detected as grayscale are converted to gray before gamma is applied, and 16-bit images use the same 8-bit samples as KCC.

## Not yet

- Notifications are the system's, so they appear only when notifications are allowed for Manga2Ink. Notification delivery has not been manually checked on unsigned macOS builds or the portable Windows ZIP.
- On a Mac, closing the window of a running conversion lets the computer sleep again, though conversion continues.
- Updating is manual: the installers are unsigned and there is no update feed.
