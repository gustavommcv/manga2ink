# Manga2Ink v0.1.0-beta.1

This is the first beta. The packages are unsigned, and installation and updates are manual. Use `SHA256SUMS` to check your download. [Installation guide](https://gustavommcv.github.io/manga2ink/getting-started/installation/)

## Added

- **Kindle 1440x1920** is now a device profile. It starts with 16-level grayscale and image enlargement off.

## Fixed

- **Reduce rainbow effect** now turns off when you switch to a monochrome device profile. You can still turn it on for that device.

## Documentation

- The guide explains how to organize a series into books or make one book for the whole series, even if the chapter names have no volume numbers. [Organizing books and volumes](https://gustavommcv.github.io/manga2ink/user-guide/mapping-editor/)

Bundled: mangabind v0.10.0, mangaprep v0.9.1. [Full changelog](https://github.com/gustavommcv/manga2ink/compare/v0.1.0-alpha.20...v0.1.0-beta.1)
