# Manga2Ink v0.1.0-alpha.20

An alpha: the installers are not code-signed. How to install, and what to expect from the system, is in the [installation guide](https://gustavommcv.github.io/manga2ink/getting-started/installation/). `SHA256SUMS` checks the downloads.

## Before you update

- **The checkbox "Create one book for the series" is gone.** Whether a series is one book is now chosen for each series, under **Books** in **Edit books and volumes**: one book per volume, one for the whole series, or the folder converted as it is. A choice kept in the old setting is not carried over; choose again for the series that should be one book.

## Added

- **Choose between the versions of a chapter.** When two files hold the same chapter (the same chapter from two scan groups, say), the row says **Choose versions** and the window asks which to use: one, both side by side, or neither. Each file is shown by its first page. The choice is kept with the folder, so it is there when the folder is added again, and nothing runs until every chapter is decided.
- **One book for the whole series, with no volumes needed.** A series whose chapters carry no volume can be one book: its table of contents is the chapters alone (`Ch.1`, `Ch.2`, …). A series that has volumes keeps them as the first level. A library chooses for each title between one book per volume and one book for the title.
- **The queue says when a series' own choice overrides the steps.** A series made one book is joined and converted, and a folder left as it is is only converted, whatever the steps say; the row tells so under its name.
- **A source that has the series but no volumes for it says so.** Searching MangaDex for a series published without volumes used to end in silence; it now shows a notice, applies nothing, and points to the whole-series book.
- **A refined mascot** in the app icon, the About page and the website.

## Changed

- **Chapters are named by their number in the table of contents** (`Ch.6 - Title`), not by their place in the volume, so a book says chapter 8 when it is chapter 8 even if chapter 3 is missing.
- **Chapter names such as `Ch.0001 (en) [Group]` are read,** with their language and group, as the MangaDex downloaders name them.
- **The button of a folder's row is now Edit books and volumes,** since that is where the books are chosen.

## Fixed

- **A folder of CBZ chapters is joined before it is converted,** also with grouping skipped. In alpha.19 it stopped after the queue had said the folder was ready.
- **The taskbar shows the app's icon,** and not Electron's, when the app is started from its folder (`npm start`).

## Not yet

- The titles of a library do not ask which version of a chapter to use.
- Notifications are the system's, so they appear only when notifications are allowed for Manga2Ink. Notification delivery has not been manually checked on unsigned macOS builds or the portable Windows ZIP.
- On a Mac, closing the window of a running conversion lets the computer sleep again, though conversion continues.
- Updating is manual: the installers are unsigned and there is no update feed.
