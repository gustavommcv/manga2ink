# i18n

What the app says, in each of its languages (ADR 0052). Plain TypeScript with no React, Electron or Node, so the window, the main process and the workflows can all write the same words.

- `messages.ts` composes the parts of the app into one `Messages` object for each language, and names each language in itself. A part is a module with its messages for every language (`Record<Language, …>`), so a message that is missing in a language is a compile error, and adding a language is one entry in each part.
- `app-settings-messages.ts` (which also names each theme, ADR 0066), `about-messages.ts`, `processing-messages.ts`, `queue-messages.ts`, `running-messages.ts`, `results-messages.ts`, `sharing-messages.ts`, `mapping-messages.ts`, `library-messages.ts`, `details-messages.ts`, `options-messages.ts`, `option-fields-messages.ts`, `settings-messages.ts`, `shared-messages.ts`: the words of the settings dialog, of its About tab (ADR 0054), of its Processing tab (ADR 0056), the queue screen, the screen of a conversion going on, the screen of the books it made, the Share button with its panel, the editor of the chapter-to-volume mapping with its list of sources, the screen of a library, the details of a book with its author lookup and covers, the pages of the conversion options and the fields on them with the names of the options, the controls the conversion options share, and what every screen shares. Everything the window shows is in a catalog, except the name of the app, and `npm run lint` refuses text written in a component (`eslint-rules/no-literal-text.mjs`, ADR 0052): add the words to the catalog of the screen and read them with `useMessages()`, or, for a sentence that comes from outside the window, make it a code (ADR 0053).
- `say.ts` and the `*-said.ts` modules (`queue`, `mode`, `input`, `mapping`, `library` and `covers`, `options`, `run`, `warnings`, `toolchain`, `failure`, `notice`, `workflow`, `save`, `provider`, `text`): what the domain, the workflows, the adapters and the main process say by code (ADR 0053), a module for each of the modules of `src/domain/messages/`. A message is `{ id, values }`, declared in `src/domain/messages/`; a part of the app has a module with a function for each of its codes, in every language, and `say()` writes a message (`sayAll()` a note of several). A code with no sentence in a language is a compile error. `tests/unit/i18n-said.test.ts` has a row for every code and every form it has (the queue's in the test itself, what is said when something cannot be done in `tests/unit/support/said-failure-rows.ts`), with its English (what the app has always said, character for character) and its Portuguese.
- `dialog-messages.ts`: the titles and filters the main process gives the native dialogs, and what its notification says when a long queue ends (ADR 0065), in each language; `src/main/ipc/dialog-words.ts` picks the language the window is in.
- `day.ts`: the day of a date, as the language writes dates and in UTC, for the day a release was published.
- `size.ts`: how much room there is, in the unit that keeps the number small and as the language writes numbers.
- `count.ts`: the form of a word that goes with a count (the singular for exactly one, the plural for the rest). Japanese has no plural: it writes the same text for both forms, with the counter of what is counted (`docs/translation/ja.md`, ADR 0084).
- `sentence-marks.ts` and the separator `namesOf` takes: how a language joins the sentences of a note, ends one the window ends itself and writes a list. Japanese is the app's third catalog (ADR 0084), written with the help of AI and open to correction, and it says so under the choice of language (`appSettings.language.note`).

It is under the 100% unit gate. `tests/unit/i18n-messages.test.ts` says every message that is a function, in every language and in each form it has, and fails for one with no sample, so a message cannot be added without being said once in each language.

It may import the domain and nothing else (ESLint enforces it, ADR 0001), and the renderer, the main process, the application layer and the adapters may import it.
